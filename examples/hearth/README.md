# Hearth demo board

This folder is a demo of TBD Board. Hearth is a fictional household-chores app. All names, cards, and decisions here are made up.
Open `board.html` in a browser to try the board. Add `?theme=dark` to the address for the dark theme.
`log.md` is the decision log that belongs to the board. The command `node tools/make_media.mjs` writes these files again.
